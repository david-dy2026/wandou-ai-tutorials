# 教程整理与发布方法

[返回总目录](../README.md)

本页供维护“豌豆 AI 实战教程”时使用。首页负责导航，每个分类收录教程链接，每篇教程保存正文与配图。

## 1. 先确定主分类

| 分类目录 | 放什么 |
| --- | --- |
| `tutorials/getting-started/` | 工具安装、设置与入门 |
| `tutorials/content-creation/` | 图文教程、公众号、短视频与内容分析 |
| `tutorials/productivity/` | 资料、文档、表格与工作提效 |
| `tutorials/skills/` | Skill 安装、调用、更新与使用案例 |

一篇教程只保存一份正文。适合多个分类时，在其他分类加链接即可。

## 2. 给教程单独建文件夹

文件夹名称用简短的英文或拼音，小写单词之间用短横线连接；文章标题使用清楚的中文。

例如，未来发布一篇公众号改写教程时，可以这样存放：

```text
tutorials/
└── content-creation/
    └── tutorial-to-wechat/
        ├── README.md
        └── images/
            ├── 01-input.png
            └── 02-result.png
```

上面仅是目录示例，目前还没有这篇教程或这些截图。

## 3. 复制模板，填入实际内容

从 [教程模板](../templates/tutorial-template.md) 复制内容，保存为新教程的 `README.md`。

用实际做过的步骤、提示词和结果填写。删除模板提示和不适用的部分；没有验证的内容标明“待验证”，不要写成已经成功。

正文中引用同目录截图的写法：

```markdown
![填写材料后的界面](./images/01-input.png)
```

截图紧跟对应步骤。使用相对路径，不使用电脑上的绝对路径，这样别人打开仓库也能看到图片。

## 4. 更新分类目录和首页

在对应分类的 `README.md` 中，把「教程目录」下的待补充说明换成真实教程条目。例如：

```markdown
- [把一篇教程改成公众号文章](./tutorial-to-wechat/README.md)：使用自己的原稿，整理出标题、开头和文章正文。
```

只有正文实际存在时才添加链接。

把新教程加到对应分类页，读者即可从总库首页进入。发布已验证教程时标明验证环境和日期；若公开的是草稿，在目录中也标明“草稿”或“待验证”。

## 5. 发布并检查

把教程正文、截图、分类目录和首页修改一起提交到本仓库。

在 GitHub 上打开刚发布的教程，检查：

- 首页和分类目录能进入正文。
- 图片能显示，提示词能完整复制。
- 工具及 Skill 链接指向正确页面。
- 操作步骤、实际结果和验证状态相符。

更新已有教程时直接修改同一篇正文，并补一条更新记录。

## 以后可以这样交给 AI 整理

```text
把这份教程整理进“豌豆 AI 实战教程”总库：
https://github.com/david-dy2026/wandouskills

请先阅读仓库首页、发布方法和目标分类目录。
根据材料选择合适分类，使用已有教程模板，保留真实操作步骤和截图。
已经存在同一篇教程时更新原文，避免重复创建。
更新分类目录，完成后检查正文、图片与链接。
缺少的实测或材料标明待补，不要编造已经完成的结果。
```

发出这段需求时，一并提供本次教程材料或明确的本地文件路径。
