## 添加教程

以一个具体任务为单位，例如安装某个 Skill、更新已有安装，或用一个 Skill 完成一项真实工作。

每篇教程单独建一个文件夹，把正文保存为 `README.md`，截图放进同一文件夹内的 `images/`。发布后，在本页「教程目录」添加标题链接和一句话用途。
