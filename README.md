## 教程怎么读

每篇教程会尽量写清楚：

1. **做完得到什么**：先看这件事是不是你需要的。
2. **需要准备什么**：工具、材料和必要条件。
3. **具体怎么做**：按步骤操作，提示词可以直接复制。
4. **怎样确认成功**：对照实际结果和关键截图。
5. **遇到问题怎么办**：记录实际遇到的卡点和解决方法。

教程会注明适用环境、验证情况和更新日期，方便判断是否适合当前使用的工具。
